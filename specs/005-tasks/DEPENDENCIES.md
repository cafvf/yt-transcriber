# Task Dependencies

Version: **1.0.0**
Status: **Approved / Frozen**

The graph is implementation-aware rather than a mechanical copy of REQ dependencies. Cross-cutting architecture requirements may use a foundation task followed by a closure owner so dependent migrations can proceed incrementally without falsely declaring the parent REQ complete.

This refinement does not change the frozen REQ dependency semantics: foundations provide the minimum seam needed for dependent migration, and the relevant closure task must still pass before the PLAN gate can pass.

Cross-plan dependencies enter through the immediate prior plan gate. Same-plan dependencies list only concrete predecessor tasks needed for safe execution. Gate tasks depend on every task in their plan.
