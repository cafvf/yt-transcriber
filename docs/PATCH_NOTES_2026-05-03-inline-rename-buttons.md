# Patch notes — 2026-05-03 — Future feature: inline rename buttons

## Alteração documental

Acrescentada ao roadmap de funcionalidades futuras a seção:

- `B.4 Renomeação de falantes por botões inline`

A funcionalidade propõe usar botões inline do Telegram para renomear `SPEAKER_00`, `SPEAKER_01`, etc., sem exigir comando textual `/rename`. O fluxo previsto inclui seleção do falante por botão, captura do nome por mensagem, atualização do snapshot JSON e re-renderização do Markdown.

## Observações

Esta versão não implementa o handler Telegram; apenas registra a funcionalidade no backlog documentado.
