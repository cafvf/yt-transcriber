# Patch notes — 2026-05-03 — roadmap de vídeo legendado

Esta versão atualiza a documentação de funcionalidades futuras com a funcionalidade solicitada de devolver uma cópia do vídeo com legendas incorporadas.

## Alterações

- Adicionada a seção `D.5 Vídeo com legendas incorporadas` em `docs/06-funcionalidades-futuras.md`.
- A seção diferencia duas variantes:
  - legenda selecionável/soft subtitles;
  - legenda queimada/hard subtitles.
- Foram registrados comandos futuros sugeridos, pipeline técnico provável, limitações de tamanho no Telegram, dependência de SRT/VTT e recomendação de uso de ASS para estilo avançado.

Nenhuma funcionalidade de runtime foi implementada nesta versão; é uma atualização de roadmap/documentação.
